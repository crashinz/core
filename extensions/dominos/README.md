# Dominos (All Fives)

First-party double-six All Fives for 2-4 individuals or four opposite-seat partners.
The configurable display name and the All Fives qualifier are separate. Rules,
legal actions, scoring and verified deals are server-authoritative. See the in-game
Rules panel for the complete variation, including randomized starter cycles.

Normal bots can fill empty lobby seats. Any bot makes the game Practice only.
Bots use their own hand and public information. A sampled-reply candidate remains
experimental and is not offered as Expert; initial paired trials did not establish
an improvement across all table modes.

Select a tile and a highlighted end, or drag a playable tile there. Click the
selected tile again to cancel. Board size is 50-200%. Sound FX and Visual FX are
independent viewer preferences. Thinking and retry controls stay below the board.

Recordings, saved games, rematches and seats use the shared multiplayer framework.
Original board/tile artwork is code-native SVG/CSS. Audio attribution and licenses
are in the central THIRD_PARTY_NOTICES.md, under Dominos placement and shuffle sounds.

Expert uses bounded public-information sampling, complete-round rollouts and sampled endgame search. Normal remains unchanged. All bot games are Practice only.
