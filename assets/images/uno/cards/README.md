CoreChat distributes only the selected numbered, Draw Two, Reverse, Skip, Wild,
and Wild Draw Four PNGs from that CC0 pack under this directory. Files were
renamed for stable runtime lookup. The source sprite sheets, unused black
number cards, blank cards, color-specific Draw Four cards, source card backs,
and URL shortcut are not distributed.

`back.png` is original repository artwork generated for CoreChat on 2026-08-26
and normalized to the existing card dimensions. It is not sourced from the CC0
pack and intentionally contains no official UNO logo or text.
